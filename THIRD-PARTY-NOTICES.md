# Third-party notices

exr-rs is a Rust port of several C and C++ projects. Each ported crate keeps the license of
the project it ports, with the original copyright notices plus the port's own line
(see each crate's `LICENSE`):

| Crate | Ports | License |
|---|---|---|
| `exr-core`, `exr-util`, `openexr-py`, `exr-rs` CLI | OpenEXR | BSD-3-Clause |
| `imath-rs` | Imath | BSD-3-Clause |
| `deflate-rs` | libdeflate | MIT |
| `cryptomatte` | Cryptomatte | BSD-3-Clause |
| `exr-gpu`, `exr-view`, `exr-image`, `exr-test-data` | original code | BSD-3-Clause (`LICENSE`) |

The ports' upstream notices follow, together with those of the ported projects that reach
the `exr-rs` binary through git dependencies. Pinned upstream versions are listed in
`README.md` ("Reference sources"). The license texts of every Rust crate compiled into
the binary (crates.io and git dependencies alike) ship in `THIRD-PARTY-LICENSES.html`,
generated by `cargo about` when a release ZIP is packaged.
